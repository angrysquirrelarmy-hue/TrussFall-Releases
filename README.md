# TrussFall

Build houses. Badly. Together.

A goofy co-op construction game for up to four players: punch footing holes, stand the posts, nail up the walls, wire it, plumb it, paint it, and get it past the inspector before Mother Nature has her say.

## Install (Windows 10 / 11)

1. Open the [latest release](https://github.com/angrysquirrelarmy-hue/TrussFall-Releases/releases/latest).
2. Download **TrussFallLauncher.exe** and run it.
3. Press **INSTALL**. The game downloads into `%LOCALAPPDATA%\TrussFall` (about 400 MB), and TrussFall shortcuts appear on your desktop and in the Start menu.

## Updates

Open TrussFall from its shortcut. The launcher checks for a newer build every time it opens; **UPDATE** downloads only the files that changed. Then press **PLAY**.

Your saved houses and settings are kept in your AppData, so updating (or uninstalling) never touches them.

Windows SmartScreen may warn about the launcher because it isn't code-signed: choose **More info > Run anyway**.
